# Per-turn resource receipt

Every turn using tools or involving an actual worker launch or participation ends with exactly one `TASK RESOURCE SNAPSHOT` in the final user-visible response, after `ROUTE END` when present. Pure text without tools or workers is exempt. Simple and status turns need no orchestration solely for this receipt. Never launch a model for accounting.

Use authoritative current-turn host evidence when available. Give one row per observed runtime model and reasoning effort, with input, cached input (included in input), output (including reasoning), total, and uncached/reasoning where available. Include actual current-turn worker count, observed/partial/unknown status, reason and scope. An unobserved pair or missing field is unknown, not zero; distinguish observed numeric zero. A known worker without usage needs an explicit unknown row or labeled gap. Attribute shared-pair workers clearly. Never infer runtime from plans or count historical edges, attempts or token rows as workers.

For Codex use [the adapter](scripts/codex-task-resource-snapshot.py) at the pre-final checkpoint when available; `--workers N` supplies an independently confirmed current-turn count (including zero), and omission leaves it unknown. Report a known worker missing from telemetry as a gap. Other hosts use equivalent evidence or unknown; do not add collectors. Independent CLI workers require a true per-turn event or a trustworthy same-session before/after difference, including a proven-zero fresh baseline. Absent, decreasing, inconsistent, ambiguous or overlapping baselines are unknown. Do not add lifetime/resume totals or double-count native child rows; report independent rows separately if inclusion is unproven.

Cache counts are descriptive telemetry. The checkpoint excludes the final response and later events and is not a bill. Portable-only hosts must bind this rule into an always-loaded instruction layer for turns with no selected skill. This is an instruction contract, not a universal UI hook; existing sessions and uncooperative apps may not reload it.
